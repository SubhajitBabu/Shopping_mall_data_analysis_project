# Shopping Mall Sales Report

The Shopping Mall Sales Report is an end-to-end data analysis project developed using **MySQL, Excel, and Power BI**. The project focuses on analyzing retail sales data to understand customer purchasing behavior, sales performance, product categories, payment methods, shopping mall performance, and overall business trends.

## Tools & Technologies

* **MySQL** – Data cleaning, transformation, SQL queries, aggregation, and analysis
* **Microsoft Excel** – Data validation, exploratory analysis, calculations, and supporting analysis
* **Power BI** – Interactive dashboard, KPI visualization, charts, filters, and business insights

## Dataset

The dataset contains retail transaction information such as:

* Invoice Number
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price
* Payment Method
* Invoice Date
* Shopping Mall

## Data Analysis

The project analyzes important business metrics including:

* Total Sales
* Total Transactions
* Total Customers
* Total Quantity Sold
* Average Order Value
* Sales by Gender
* Sales by Product Category
* Sales by Shopping Mall
* Sales by Payment Method
* Sales by Year and Month
* Customer and purchasing patterns
* Category-wise sales performance

## MySQL Analysis

MySQL is used to perform SQL-based analysis using functions such as `SUM()`, `COUNT()`, `COUNT(DISTINCT)`, `AVG()`, `GROUP BY`, `ORDER BY`, and date-based analysis. Separate analytical queries are created to calculate KPIs and identify sales trends and customer patterns.

## Excel Analysis

Excel is used for data checking, validation, calculations, and exploratory analysis. Pivot tables and Excel-based summaries can be used to examine sales across categories, genders, malls, payment methods, and time periods.

## Power BI Dashboard

The final analysis is presented through an interactive Power BI dashboard containing KPI cards, charts, tables, and filters. Users can interact with the dashboard to explore sales performance by category, gender, shopping mall, payment method, and time period.

## Project Objective

The main objective of this project is to transform raw shopping mall transaction data into meaningful business insights and demonstrate practical skills in **SQL, Excel, data analysis, data visualization, and Power BI dashboard development**.
